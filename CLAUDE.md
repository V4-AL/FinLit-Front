## Design Context

This project has strategic and visual design context captured for AI agents to reference before making UI changes:

- **`PRODUCT.md`** — register (product), platform (web/no native rulebook), target users (young adults/students building first money habits), positioning ("makes financial literacy feel like a game you actually want to play daily"), brand personality (encouraging, playful, trustworthy), and anti-references (avoid a stuffy corporate bank-app feel).
- **`DESIGN.md`** — the actual visual system in use: colors, typography, spacing, elevation, and component patterns, extracted from `src/contexts/ThemeContext.tsx` and the existing screens. North star: "The Trusted Playground" — playful game mechanics (streaks, XP, levels) on a calm, flat, bordered, credible shell.

Read both before designing or reviewing any UI work in this repo.
